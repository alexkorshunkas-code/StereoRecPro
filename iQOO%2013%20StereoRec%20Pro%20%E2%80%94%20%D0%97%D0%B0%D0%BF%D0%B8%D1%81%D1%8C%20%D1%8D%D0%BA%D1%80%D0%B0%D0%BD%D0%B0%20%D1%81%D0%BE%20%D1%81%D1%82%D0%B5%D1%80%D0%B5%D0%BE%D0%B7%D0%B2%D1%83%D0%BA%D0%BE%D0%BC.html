📱 Как установить нативный APK на ваш iQOO 13

Я подготовил для вас полный архив Android-проекта iQOO13_StereoRec_Android_Project.zip со встроенным облачным сборщиком APK.

Шаг 1. Скачайте архив проекта

Скачайте прикреплённый в чате файл iQOO13_StereoRec_Android_Project.zip. Внутри находятся исходники на Kotlin и скрипт автосборки build-apk.yml.

Шаг 2. Автосборка APK без ПК (2 мин)

Загрузите файлы из архива в бесплатный репозиторий на GitHub прямо из браузера телефона. GitHub Actions сам запустит Android SDK и соберёт iQOO13-StereoRec-Pro-APK.

Шаг 3. Настоящий Stereo 2.0

Приложение использует AudioPlaybackCaptureConfiguration + CHANNEL_IN_STEREO и аппаратный кодек AAC 320 кбит/с (48 кГц).

Ключевой фрагмент ядра захвата стереозвука (Kotlin • Android 10–15):
val pcmStereoFormat = AudioFormat.Builder()
    .setEncoding(AudioFormat.ENCODING_PCM_16BIT)
    .setSampleRate(48000)
    .setChannelMask(AudioFormat.CHANNEL_IN_STEREO) // Полноценные 2 канала (Left + Right)
    .build()

val playbackConfig = AudioPlaybackCaptureConfiguration.Builder(mediaProjection)
    .addMatchingUsage(AudioAttributes.USAGE_GAME)
    .addMatchingUsage(AudioAttributes.USAGE_MEDIA)
    .build()

val internalAudioRecord = AudioRecord.Builder()
    .setAudioFormat(pcmStereoFormat)
    .setBufferSizeInBytes(minBufSize * 2)
    .setAudioPlaybackCaptureConfig(playbackConfig)
    .build()
